# ai-logs

Minh chứng Vibe Coding (tiêu chí C1, C2):

- lịch sử hội thoại với trợ lý AI ở các phiên làm việc chính;
- video quay màn hình các phiên quan trọng (file lớn để link Google Drive, không đẩy video lên đây);
- nhật ký kiểm chứng: mỗi lần nhờ AI viết mã, ghi phép thử, lỗi phát hiện, cách sửa và commit liên quan.
